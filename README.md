# 英国出差英语口语手册

每日定时任务「每日英语口语手册（英国出差）」生成的全部篇目，同步自 claude.ai 上的总入口页面。

- **网页入口**：<https://liujunyukarry.github.io/claude-english/>
- **当前收录**：Day 01–55（2026-08-25 至 2026-10-18）

> 定时任务每天只更新 claude.ai 上的总入口页面，不会自动推送到本仓库。本仓库是某一时刻的快照，要更新需要再同步一次。

## 目录结构

```text
index.html    # 主页面：样式、朗读脚本、篇目目录 META 和最新一篇 LATEST
d/N.js        # 第 N 篇正文，切换篇目时由 index.html 按需加载
```

每篇固定八节：今天只记这 3 句／核心表达／短语速查／完整对话／难词发音／容易说错的 3 个点／实务／听懂英国人。点句子旁的 🔊 用浏览器自带的英式语音朗读。

## 同步方法

从总入口原样下载 `index.html` 和 `d/*.js`，覆盖到仓库根目录同名位置即可，不需要构建。
